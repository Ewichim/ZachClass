# FIRE references

- [Exploration of Burning Plasmas in FIRE](https://fire.pppl.gov/fec2002_FT2_6_reprint4.pdf),
  D. M. Meade and colleagues, 2002: the 2.14 m major-radius design, with H-mode
  and advanced-tokamak operating points. Local copy:
  `Meade_2002_Exploration_of_Burning_Plasmas.pdf`.
- [Physics Design Guidelines](https://fire.pppl.gov/ANS_Uckan_Wesley.pdf),
  N. A. Uckan and J. C. Wesley: an earlier design with a 2.0 m major radius.
  Local copy: `Uckan_Wesley_Physics_Design_Guidelines.pdf`.

`FIRE_2002_parameters.csv` is a manual transcription of selected values from
Table I in the Meade paper, printed page 3 (PDF page 4). It separates the
H-mode and reversed-shear advanced-tokamak columns. It is reference data,
not a ready-to-run input file for either POPCON package.

Keep these design versions separate when choosing inputs. The CSV records
published values without evaluating the performance claims.
